# Week 2 — Programming Concepts & Fundamentals

## Overview

Week 2 continues the study of **C# Programming** by completing the remaining topics from **Chapter 1** and introducing the first concepts of **Chapter 2**.

The week focuses on programming fundamentals, problem-solving techniques, program development, basic program structure, data types, and variables.



## ?? Chapters Covered

### Chapter 1 — Introduction to Visual C#

This week completes the remaining topics of Chapter 1, including:

* Programming Fundamentals
* Syntax
* Semantics
* Compilation and Interpretation
* Program Development Cycle
* Problem Definition
* Design
* Coding
* Testing and Debugging
* Documentation and Maintenance
* Problem-Solving Tools
* Algorithms
* Pseudocode
* Flowcharts

### Chapter 2 — Processing Data

The week begins Chapter 2 and covers the introductory concepts up to **Variables**, including:

* Structure of a Program
* Input
* Processing
* Output
* Data Types
* Integers
* Floating-Point Numbers
* Characters
* Strings
* Booleans
* Variables
* Variable Naming Rules
* Declaration
* Initialization



## ?? Learning Objectives

By the end of Week 2, I should be able to:

* Explain the basic concepts of programming.
* Understand syntax and semantics.
* Explain the difference between compilation and interpretation.
* Describe the program development cycle.
* Use algorithms to describe solutions.
* Understand pseudocode and flowcharts.
* Explain Input, Processing, and Output.
* Identify common C# data types.
* Explain what variables are.
* Apply basic variable naming rules.
* Understand declaration and initialization.
