# C# Programming Course

A structured repository for my **C# Programming Course**, documenting my learning journey from the fundamentals of C# programming to database programming and desktop application development.

This repository contains my course notes, source code, exercises, projects, and screenshots**, organized by chapter for easy learning and reference.



## 📖 About the Course


### What is C#?

**C# (C-Sharp)** is a modern, object-oriented programming language developed by Microsoft. It is commonly used to build console applications, desktop applications, web applications, APIs, games, and database-driven applications.

### What is .NET?

**.NET** is Microsoft's development platform that provides the tools, libraries, and runtime needed to build and run applications using C#.

### What is Visual Studio?

**Visual Studio** is Microsoft's IDE used throughout this course to create projects, write code, run applications, debug programs, and manage project files.



## 🎯 Course Goal

The goal of this course is to build a strong foundation in C# programming and gradually apply programming concepts to practical applications.

**Learning Path:**

`C# Fundamentals → Data Processing → Decisions → Loops & Files → Methods → Arrays & Lists → ADO.NET → Sample Project → Desktop Application`

# 📖 Chapters Overview

## Chapter 1 — Introduction to Visual C#

This chapter introduces the fundamentals of C# programming and the .NET platform. It covers how to create and manage C# projects using Visual Studio, understand the basic structure of a C# program, and write simple console applications.

Topics include variables, comments, basic syntax, console input/output, running applications, and debugging programs.



## Chapter 2 — Processing Data

This chapter focuses on how C# programs work with and process different types of data.

It covers variables, data types, constants, type conversion, arithmetic and assignment operators, strings, string formatting, and basic data processing techniques.

These concepts provide the foundation for working with information inside C# applications.



## Chapter 3 — Making Decisions

This chapter introduces decision-making and conditional programming.

It explains how programs can make different decisions based on conditions using `if`, `else`, `else if`, and `switch` statements.

It also covers comparison operators, logical operators, and combining multiple conditions to control program behavior.



## Chapter 4 — Loops, Files, and Random Numbers

This chapter focuses on repetition, file handling, and generating random values.

It covers `for`, `while`, and `do-while` loops for repeating tasks. It also introduces reading and writing files using `StreamReader` and `StreamWriter`.

The chapter also covers random number generation and demonstrates how loops, files, and random values can be used together in practical programs.



## Chapter 5 — Methods

This chapter explains how to organize C# programs into reusable blocks of code called methods.

It covers creating and calling methods, parameters, return values, optional parameters, `ref` and `out` parameters, and method overloading.

The main goal is to write code that is more organized, reusable, readable, and easier to maintain.




## Chapter 6 — Arrays and Lists

This chapter introduces collections for storing and managing multiple values.

It covers one-dimensional and multi-dimensional arrays, as well as `List<T>` collections.

Topics include adding and removing elements, accessing data, searching, sorting, iterating through collections, and understanding when to use arrays or lists.



## Chapter 7 — ADO.NET

This chapter introduces database programming with C#.

It explains how C# applications communicate with SQL databases using **ADO.NET**.

Topics include:

* Database connections
* `SqlConnection`
* `SqlCommand`
* `SqlDataReader`
* Executing SQL queries
* CRUD operations
* Parameterized queries
* Reading data from databases
* Inserting, updating, and deleting records

The chapter provides practical experience with connecting C# applications to databases and working with stored data.




## 🧪 Sample Project

The Sample Project brings together the programming concepts learned in Chapters 1–7.

It provides practical experience in building a small application using:

* Variables and data types
* Conditional statements
* Loops
* Methods
* Arrays and lists
* Database connectivity
* CRUD operations
* Error handling

This project demonstrates how individual programming concepts can work together to create a complete application.



## Chapter 8 — Desktop Application Development

This chapter introduces desktop application development using C#.

It focuses on creating applications with graphical user interfaces and working with forms, controls, events, and user interactions.

The chapter also covers connecting desktop applications to databases and applying previously learned C# and ADO.NET concepts to build functional desktop applications.
